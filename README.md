EFMrep is a tool to combine STR DNA samples into one LR calculation.

Requires euroformix R-package installed (newer than version 3.0.0).
Other packages are optional.

Installation for Windows (GitHub release):
install.packages('https://github.com/oyvble/EFMrep/releases/download/v1.1.0/EFMrep_1.1.0.zip',repos=NULL,type='win.binary')

Compile own version from GitHub (source):
install_github("oyvble/EFMrep")
